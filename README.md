# 성적서 발급검증

CSI에서 내려받은 **품질시험 성적서 발급 대장**을 기준으로 회사 관리프로그램의 **성적서발행발송리스트**와 사내 **접수대장(건설 시트)**의 발급일자·성적서번호 입력을 3자 검증하는 Windows 전용 무설치 프로그램입니다.

## 핵심 규칙

- CSI 발급대장 `Sheet0`을 기준 원본으로 사용
- 발행리스트의 `일반접수`는 비교에서 제외
- 접수번호 1건 = 성적서번호 1개
- 접수번호를 1차 키로 사용하고 공사명/업체명을 보조 검증
- 시료명은 표기 체계 차이가 커 상세 참고값으로만 사용
- 일반 발급(`-00`): 접수대장 `발급일자`와 비교
- 수정 발급(`-01`, `-02`...): 접수대장 기존 발급일은 유지하고 `수정발급일자`와 CSI 날짜를 비교
- 관리프로그램은 수정성적서에서도 현재 발행일만 CSI와 비교
- CSI에는 없지만 다른 파일에 발급정보가 있으면 자동 오류가 아니라 `확인 필요`

## 사용 흐름

1. CSI 발급대장과 발행리스트를 공용 드롭존에 드래그합니다.
2. 프로그램이 파일명 + 내부 구조로 두 파일을 자동 구분합니다.
3. `Z:\`에서 최신 `접수대장*.xlsm`을 찾아 `건설` 시트만 읽습니다.
4. `검사 시작`을 누릅니다.
5. 결과는 `확인 필요` / `전체 비교` 두 탭으로 표시됩니다.
6. 표는 엑셀처럼 셀 선택 후 `Ctrl+C` 또는 우클릭 `복사`를 지원합니다.
7. 수정 후 `재검사`를 누르면 접수대장은 다시 읽고, 다운로드 폴더의 더 최신 발행리스트가 있으면 교체 여부를 묻습니다.

## 개발 실행

```powershell
py -m venv .venv
.venv\Scripts\activate
pip install -e .[dev]
certificate-validator
```

## Windows 빌드

GitHub Actions의 `windows-build.yml`이 무설치 EXE를 생성합니다.

> 업데이트 확인은 GitHub Releases API를 사용합니다. 현재 저장소가 private이면 인증 없는 API 조회가 불가능하므로, 향후 저장소를 공개하거나 별도 공개 Releases 저장소를 사용하도록 URL을 바꾸면 됩니다.
